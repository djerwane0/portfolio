Snooze Manager

Menu d’extension pour le client League of Legends, développé en JavaScript et intégré avec Pengu Loader. Le projet ajoute une interface dédiée et plusieurs options absentes du client de base.

JavaScript Pengu Loader HTML / CSS DOM
Voir le dépôt GitHub Retour

Objectif

Concevoir un menu personnalisable capable de s’intégrer à une application existante afin d’améliorer l’expérience utilisateur et de regrouper plusieurs réglages dans une interface unique. Le projet sert également à expérimenter l’automatisation de certaines actions répétitives du client.

Présentation fonctionnelle

  • Acceptation automatique des parties.
  • Relance automatique de la file d’attente.
  • Sélection de champions selon des préférences enregistrées.
  • Personnalisation du statut en ligne.
  • Ajout d’options supplémentaires dans plusieurs menus du client.
  • Gestion des paramètres depuis une interface dédiée.

Points techniques

  • Intégration du menu dans le client avec Pengu Loader.
  • Manipulation du DOM et création dynamique de composants d’interface.
  • Organisation du code en modules indépendants selon les fonctionnalités.
  • Gestion et conservation des préférences utilisateur.
  • Interaction avec l’environnement local du client League of Legends.

Compétences travaillées

  • JavaScript et programmation événementielle.
  • Conception d’interfaces utilisateur.
  • Modularisation et maintenance du code.
  • Compréhension et extension d’une application existante.
